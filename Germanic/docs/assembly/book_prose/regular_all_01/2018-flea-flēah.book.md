This word carries a genuine stem-class dispute. Orel reconstructs a root noun _\*flauxz_ with his class-wide explicit nominative marker [@Orel2003, 105]; Kroonen instead reconstructs an ō-stem _\*flauhō-_ with no _-z_ at any layer [@Kroonen2013, 145]. Old English _flēah_ and Old Norse _fló_ are compatible with both, so the class question remains open; the selected input _\*fláuxz_ adopts Orel's root-noun analysis alongside 'book', 'goose', and 'louse'.

On that analysis the nominative marker was eliminated before Proto-West Germanic [@RingeTaylor2014, 118], giving _\*fláux_; the diphthong is then fronted and levelled in Old English, yielding _flēax_, spelled _flēah_. The selected input is a stressed monosyllable, but its _\*-z_ stands after a consonant and was gone long before the northern monosyllabic loss, whose domain is vowel-final monosyllables.

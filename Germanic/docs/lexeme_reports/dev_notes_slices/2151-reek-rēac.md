## Development-note summary

The controlling note for the live row is the late project-status update at DEV_NOTES:line-1435-1439. That note explicitly says the earlier `*ráukaz → rēac` mismatch against attested `rēc` was retired when the cogset was retargeted to reconstructed West Saxon `*rēac`, and that the row is now a regular match in `reconstructed_oe`. The current slice therefore has to keep three things separate: the cognate-set etymon `*ráukiz`, the OE modelling input `*ráukaz`, and the row target `rēac` as a reconstructed citation form rather than a directly attested manuscript lemma.

The older reek dossier remains necessary because it preserves the comparative baseline that the retargeting note does not repeat. Kroonen's entry is quoted there as `"*rauki- m. 'smoke' — ... OE réc m. 'id.' ... An i-stem derived from the strong verb *reukan- ~ *rūkan-"` [@Kroonen2013, p. 407]. In other words, the inherited comparator for the family is still i-stem `*ráukiz`, and the directly attested Old English form carried in the comparative dictionaries is `rēc`, not `rēac`. The same note also spells out the regular dialect split if one insists on that i-stem target: Campbell writes that `"The i-umlaut of ēa in West Saxon is īe"` [@Campbell1959, §201], while Ringe and Taylor state that long `*éa` was umlauted to `ie` in West Saxon but to `é` in the other dialects [@RingeTaylor2014, §6.6.3]. That is the superseded comparator behind the old mismatch: regular i-stem development points toward WS `*rīeċ` or Anglian `rēc`, not toward the live reconstructed target `rēac`.

The long philological deep-dive is still worth preserving because it records what the handbook searches did and did not find. It quotes Campbell's `§200(5)` on regular `*au`-umlaut outcomes and Ringe-Taylor on the same dialect split, then notes that Campbell, Ringe-Taylor, and Hogg do not single out `rēc` as a named irregularity, even though Kroonen still cites OE `réc` under `*rauki-` [@Campbell1959, §200(5); @RingeTaylor2014, §6.6.3; @HoggPhonology1992, §§5.79--5.83; @Kroonen2013, p. 407]. That fragment is not current row policy by itself, but it remains the best replacement-note record of the philological problem: attested `rēc` is real, handbook silence is real, and the project had to decide whether to bend the row toward attestation or toward the regular cascade.

The `*ráukaz` track enters because the FST probe showed that a no-i-trigger a-stem input already gives the reconstructed form now used by the row. DEV_NOTES records the probe verbatim: `ráukaz    rēac`, followed by the conclusion that the system produces `rēac` from `*ráukaz` because `*au` develops to `ēa` and no i-umlaut applies. Campbell's smoothing discussion is then invoked only as a follow-up question about whether `rēac` could later become `rēc` [@Campbell1959, §§279--282]. For current row purposes, the important point is narrower: `*ráukaz → rēac` is the regular comparator that now underwrites the reconstructed target.

The slice also has to preserve the abandoned detour through `*rōkiz`. The deep-dive temporarily recommended changing the row to `*rōkiz` because the FST gave `rēċ`, which looked like a neat way to reach attested `rēc` on the page. That recommendation is now explicitly dead. The later closure note says the `*rōkiz` recommendation is `withdrawn`, and it treats any proto input that yields palatal `ċ` as philologically wrong because Modern English `reek` /riːk/ and the related weak verb evidence require OE velar /k/, not palatal /tʃ/ [@ClarkHall1960, p. 255; @BosworthToller1898, s.v. `réc`]. Later report writers should therefore treat `*rōkiz` only as a superseded project workaround that solved the wrong problem.

The closure note is itself mixed-status evidence and must be read carefully. Its known-problems triage is superseded by the later retargeting note, and its proposal to switch the row's `PROTO` as well as `PROTOFORM` to `*ráukaz` no longer matches the live TSV, which now keeps `PROTO = *ráukiz` while using `PROTOFORM = *ráukaz`. But the closure still preserves two current reasons that survived the retarget: first, adding a general smoothing rule to force attested `rēc` would damage ordinary West-Saxon `ēa` words; second, the project decided that attested `rēc` should be explained in note/report prose rather than forced through the live cascade. That is why the row now stands as reconstructed `rēac`, while attested `rēc` remains the explicit philological background and the main superseded target.

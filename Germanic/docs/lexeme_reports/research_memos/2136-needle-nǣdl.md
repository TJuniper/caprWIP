## Reconstruction and early-stage forms

This row needs a strict three-way distinction.

1. **Cognate-set proto / etymological headword:** `PROTO = *nḗθlō` is the comparative headword carried by the row.
2. **Project input form for derivation:** `PROTOFORM = *nḗðlō` is the voiced Verner-grade alternant actually fed to the OE cascade.
3. **OE target form:** `nǣdl` is the attested OE citation form represented by the row.

The packet trace shows that once the project input is the voiced alternant, the rest of the derivation is regular on project terms: `*nḗðlō -> *nḗdlō -> *nḗdlu -> *nǣdlu -> *nǣdl -> nǣdl`. The real issue is therefore upstream alternant selection, not OE-side repair.

That is why the older repo line "change protoform to `*nēdlō` for the OE row" is now stale as live instruction: the row has already implemented the relevant fix in project notation by separating voiceless `PROTO` from voiced `PROTOFORM`. The memo should not collapse those into a single undifferentiated "PGmc `*nēdlō`" statement.

## Old English philology

`nǣdl` should be treated as an attested OE headword, not a reconstructed form and not a paradigm-cell substitute. `old_english_wiktionary.tsv` gives `needle = nǣdl`, `Clark Hall` lists `nædl (ē) f.`, and the cluster-class comparison in `DEV_NOTES` explicitly counts `nǣdl` among the directly attested unbroken `-Cl/-Cn/-Cm#` nouns.

The philological subtlety is not whether OE had `nǣdl`, but how to describe its consonant history and orthographic presentation:

- `Campbell` lists `nédl` among the expected unbroken forms after `t` and `d`, so the OE cluster itself is not problematic [@Campbell1959].
- `Hogg` likewise treats forms like `bosm`, `hræfn`, `spatl`, and `nidl/nǣdl` as possible syllabic-sonorant outcomes, sometimes with competing epenthetic-vowel spellings elsewhere in the class [@HoggPhonology1992, p. 96].
- The Brunner/Sievers quotation reused in `DEV_NOTES` specifically notes `nǣdl ~ nēdl`, which is useful as orthographic background but does not justify changing the row away from the attested citation form `nǣdl`.

So the safe philological claim is straightforward: the row targets attested OE `nǣdl`, an unbroken citation form; the special explanatory burden lies in the inherited voiced/voiceless alternant, not in OE attestation or paradigm-cell choice.

## Project problem and solution

The project problem was originally that the row's note already acknowledged a voiced Verner-grade source, while the older OE-facing protoform still used the voiceless consonant and therefore mismatched. The current project solution is the right kind of solution:

- keep `PROTO = *nḗθlō` as the cognate-set headword;
- keep `PROTOFORM = *nḗðlō` as the OE-facing derivational input;
- keep `COUNTERPART = nǣdl` as the attested OE target.

On that reading, `DERIVATION_CLASS = early_analogy` remains defensible. The special move is upstream selection of the voiced alternant for the OE derivation, not a late OE paradigm-cell rescue. This row is therefore closer to other early-stage stem/alternant-selection cases than to the `late_analogy` paradigm-cell rows.

## Paradigm probe

A paradigm probe is **not required**.

This row does not depend on choosing among competing OE inflectional cells. The decisive contrast is between the comparative/cognate-set `PROTO` and the voiced OE-facing `PROTOFORM`, and the live derivation trace already confirms that the selected input yields the citation form `nǣdl`. If the supervisor later wants a tiny audit table, a simple nom.sg.-style comparator of `*nḗθlō` versus `*nḗðlō` would be enough; there is no missing set of OE paradigm cells that blocks a final report.

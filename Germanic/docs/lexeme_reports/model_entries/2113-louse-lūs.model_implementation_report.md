## Notes on this pass

- Drafted the entry around the doubly secondary sibilant: the root-final `s`
  is an analogical extension of `*luw-` on the 'mouse' model (Bammesberger),
  and the nominative marker on top of it is Orel's class-wide morphological
  convention; Ringe's `*mūs` degemination carries the point that no extra
  sibilant was ever audible.
- Kroonen's dictionary has no 'louse' entry; the report and ledger record this
  as a negative finding rather than manufacturing a disagreement.
- Orel prints `*lusz` without vowel length; the entry notes the selected input
  `*lūsz` adds the macron consistent with the attested OE and ON long vowels.
- Page citations were verified directly against the local reference texts; the
  ledger records line-level locators.

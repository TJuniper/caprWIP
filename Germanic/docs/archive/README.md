# Germanic/docs archive

**Everything in this directory is ARCHIVE material: historical records that
are never authoritative for current state.** Nothing here may be edited to
change its historical claims, cited as current instruction, or used as an
input to current-state generation.

Current state lives in `Germanic/docs/CURRENT_STATE.md`; the canonical
machine-readable registries live in `Germanic/docs/sound_changes/registry/`.

Contents:

- `CANONICAL_STATE.md` + `canonical_state_freeze_report.md` — frozen
  2026-05-09 project checkpoint ("research phase complete"); superseded by
  the active adjudication programme.
- `DEV_NOTES.md` — the full historical research log (~44k lines). Valuable
  searchable scholarship; never a "start here" document.
- `WORKFLOW.md` — pre-consolidation operational workflow; superseded by
  `Germanic/docs/README.md` and the adjudication protocol.
- `HISTORICAL_CHRONOLOGY_AUDIT_PLAN.md` — the original audit plan; the
  audit it planned has been running and partly superseded it.

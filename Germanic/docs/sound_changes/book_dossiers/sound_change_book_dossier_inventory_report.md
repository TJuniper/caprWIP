## 4. Sound-change mini-chapter template

A reusable mini-chapter can now be framed as:

1. **Name and formulation**
2. **Traditional description and literature**
3. **Formal implementation**
4. **Place in the cascade**
5. **Order-testing evidence**
6. **Interpretation**
7. **Relation to neighboring changes**
8. **Remaining uncertainty**

## 5. Relation to the already-written lexical half

The analogy to the already-written lexical/philological half is now explicit. In the lexical half, a lexical item is built up through an evidence dossier, source comparison, philological judgement, and then a written section. In the sound-change half, the comparable unit is a sound change moving through implementation evidence, literature evidence, chronology placement, order-testing evidence, and then a written mini-chapter. The sound-change half will appear **first** in the book, but the dossier logic mirrors the lexical half rather than replacing it with graphs or runner artifacts.

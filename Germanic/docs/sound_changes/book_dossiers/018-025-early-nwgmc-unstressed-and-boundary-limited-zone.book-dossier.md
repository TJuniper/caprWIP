## Role in the book

The former `SC018-SC025` row remains useful only as an editorial and
computational holding zone between the promoted `SC016-SC020` corridor and the
promoted `SC026-SC027` nasal-spirant corridor. It is **not** a coherent
historical subgroup. The settled SC021 and SC022 adjudications make that point
explicit:

- `SC021` is retired as an active sound change. Its former
  `PNWGmcUnstressedORaising` analysis must not be promoted as a chapter,
  chronology node, or future singleton candidate.
- `SC022` remains executable as stable identifier `PNWGmcMnDissimilation`, but
  its historical classification is late Proto-Germanic / Common Germanic, not
  specifically Northwest Germanic.

The live purpose of this dossier is therefore bookkeeping: record which current
rules still have only boundary-limited order evidence and prevent the old
holding-zone label from turning into a historical claim.

## What the chronology cards currently show

The current cards divide the row into three editorial classes.

### Boundary-limited current members

- `SC018` `NWGmcStressedMonosyllableORaising`
- `SC025` `NWGmcLongENasalRounding`

Both are negative / boundary-limited on both sides. Their earlier search stops
at bundled `PWGmcChanges`, and their later search reaches the current search
boundary without a real break. The book should therefore keep them visible
without narrating positive local chronology that the current testing does not
show.

### Current member outside the NWGmc historical subgroup

- `SC022` `Common Germanic Mn Dissimilation`

SC022 has the same boundary-limited first-break profile, but it no longer
belongs historically to a Northwest-Germanic subgroup. Fulk treats the adjacent
`mn` denasalization under changes common to Germanic [@Fulk2018, p. 121,
§6.11], and Polomé describes older Germanic `-mn- > -bn-` with later leveling
obscuring the reflexes [@Polome1967, pp. 818--819]. Its stable Foma identifier
is not stage evidence.

## Why this is not yet one production chapter

The book should avoid three different overstatements:

1. It should not turn bundled `PWGmcChanges` into a historical left boundary.
   That left edge is a runner limitation, not a positive chronology claim.
2. It should not pretend that SC047 or SC056 justify a non-contiguous merged
   chapter. Those are cross-references to later promoted units, not a reason to
   collapse the chapter sequence.
3. It should not infer historical stage from the executable corridor: SC021 is
   retired, and SC022 is Common Germanic despite the stable `PNWGmc...`
   implementation name.

So the present review does **not** support promoting `SC018-SC025` as one
adjacent production report. There is no convincing internal local subgroup here
comparable to the already promoted SC029-SC030, SC039-SC040, or SC055-SC056
cores, and SC021/SC022 now explicitly prevent a blanket "early Northwest
Germanic" reading of the span.

## Plausible future shapes

### Option A: keep one broad underdetermination scaffold

This is the safest current option. It preserves the chronological place of the
region between the SC016-SC020 pilot corridor and SC026-SC027 without forcing
an artificial internal story.

### Option B: split into boundary notes plus later singleton notes

This is the clearest later split if the project wants more explicit prose.

- boundary/context notes: `SC018`, `SC025`
- Common-Germanic context note: `SC022`
- Proto-Germanic context note: `SC023` (stage corrected 2026; executable
  position 23 is a holding-zone placement only)
- Anglo-Frisian context note: `SC024` (stage/scope corrected 2026; the
  fronted `*ǣ` outcome is Anglo-Frisian, not pan-NWGmc)
- later singleton candidates: `SC023`, `SC024`
- retired note: archival `SC021` only, with live cross-reference to
  SC071/SC099/SC100

This split would respect both the source review and the order evidence. It
would also keep the outward SC047 / SC056 relations as cross-references instead
of turning them into non-contiguous chapter mergers.

### Option C: one cautious underdetermination report

This remains possible only if the book explicitly presents the row as a mixed
editorial holding zone with no strong internal historical core. It must not be
written as a positive Northwest-Germanic adjacent cluster.

## Working editorial recommendation

Keep `SC018-SC025` scaffolded for now and treat this row as
**dossier-prepared, pending human chapter-shape review**. The dossiers now
support a constrained editorial choice:

1. keep one broad scaffolded underdetermination zone; or
2. split later into boundary-limited singleton notes, a Common-Germanic SC022
   context note, and source-backed singleton notes for the still-live
   later-facing members.

If the project chooses to promote anything later, the defensible narrow
candidates from this span are `SC023` and `SC024`; SC021 is retired and must
not re-enter promotion machinery. If it chooses not to split yet, the present
grouped scaffold remains the safer architecture only as an editorial scaffold.
